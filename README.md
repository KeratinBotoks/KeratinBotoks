# 🎮 Симулятор Магната

Telegram-игра в стиле экономического симулятора, где вы начинаете с нуля и строите свою бизнес-империю.

## 🌟 Особенности

- 💰 Реалистичная экономика с медленным прогрессом
- 🏪 Различные виды бизнесов с пассивным доходом
- 📈 Реальная биржа с акциями
- 🎁 Ежедневные бонусы
- 🏆 Рейтинг игроков
- 📊 Статистика в Telegram-канале

## 🚀 Быстрый старт

### 1. Создание бота
1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Создайте нового бота: `/newbot`
4. Сохраните полученный токен

### 2. Настройка проекта
1. Клонируйте репозиторий
