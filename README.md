# 🎮 Симулятор Магната

Telegram бот - экономический симулятор. Начните с нуля и постройте бизнес-империю!

## 🚀 Быстрый старт на Railway

### 1. Создайте бота в Telegram
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Выберите имя и username для бота
4. **ВАЖНО:** Отключите режим конфиденциальности:
   - Отправьте `/mybots`
   - Выберите вашего бота
   - Bot Settings → Group Privacy → Turn OFF
5. Скопируйте токен (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Загрузите проект на GitHub
1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы этого проекта
3. Убедитесь, что есть файлы:
   - `bot.py`
   - `requirements.txt`
   - `railway.json`

### 3. Деплой на Railway
1. Перейдите на [Railway.app](https://railway.app)
2. Нажмите "Start New Project"
3. Выберите "Deploy from GitHub repo"
4. Авторизуйте доступ к вашему GitHub
5. Выберите репозиторий с ботом

### 4. Добавьте переменные окружения
1. На Railway Dashboard нажмите на ваш сервис
2. В верхнем меню выберите "Variables"
3. Нажмите "New Variable"
4. Добавьте:
   - **Key:** `BOT_TOKEN`
   - **Value:** ваш токен из @BotFather
5. Нажмите "Add"

### 5. Перезапустите сервис
1. В окне Variables нажмите "Redeploy"
2. Или в Dashboard → три точки → "Restart"

### 6. Проверьте работу
1. Найдите вашего бота в Telegram
2. Напишите `/start`
3. Должно прийти приветственное сообщение

## 🎮 Возможности бота

## 🔧 Технические детали

- **База данных:** SQLite (сохраняется между перезапусками)
- **Фреймворк:** Aiogram 3.3.0
- **Хостинг:** Railway.app (бесплатно)
- **Язык:** Python 3.10

## 🛠 Устранение проблем

### Бот не отвечает:
1. Проверьте токен в Railway Variables
2. Убедитесь, что Group Privacy выключен
3. Проверьте логи в Railway (вкладка Logs)

### Ошибки в логах:
1. Убедитесь, что все файлы загружены на GitHub
2. Проверьте версии Python (должна быть 3.10+)
3. Перезапустите сервис на Railway

### База данных не сохраняется:
1. Railway сохраняет файлы автоматически
2. Убедитесь, что нет ошибок записи в логах

## 📞 Поддержка

2. Убедитесь, что токен правильный
